# Sistema de Gestión de Estudiantes - ECOTEC

Módulo web dinámico desarrollado en PHP con arquitectura modular, base de datos MySQL/MariaDB mediante PDO (PHP Data Objects), sentencias preparadas para la prevención de Inyección SQL y sanitización de salidas contra vulnerabilidades XSS.

## 📌 Requisitos del Sistema

* **Servidor Web:** Apache / Nginx.
* **Entorno Local:** XAMPP, WAMP, Laragon o Docker.
* **Lenguaje:** PHP 8.0 o superior (con extensión `pdo_mysql` activa).
* **Gestor de Base de Datos:** MySQL / MariaDB.
